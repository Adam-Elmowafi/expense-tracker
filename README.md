# Expense Tracker
Track your daily expenses with Python

Simple expense tracking app made with Python. You can add expenses, view them, calculate totals, and filter by category.

## Features

- Add expenses with category, amount, and date
- View all your expenses
- See total amount spent
- Filter expenses by category
- Delete expenses


Then just follow the menu and choose what you want to do.
